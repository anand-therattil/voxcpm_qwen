This repository is a fork of [OpenBMB/VoxCPM](https://github.com/OpenBMB/VoxCPM) — a tokenizer-free Text-to-Speech system that generates continuous speech representations via an end-to-end diffusion autoregressive architecture. **VoxCPM2**, the base this fork builds on, is a 2B-parameter model trained on 2M+ hours of multilingual speech, built on a [MiniCPM-4](https://github.com/OpenBMB/MiniCPM) backbone, supporting 30 languages, Voice Design, and Controllable Voice Cloning.

**What this fork adds:** a proof-of-concept variant, `voxcpm2-qwen`, that replaces VoxCPM2's MiniCPM-4 text-semantic backbone with a pretrained **Qwen2.5** model, scoped initially to Hindi + English. Everything else in the pipeline — AudioVAE V2, the diffusion decoder (LocDiT), the local encoder (LocEnc), the residual acoustic LM — keeps the same architecture shape as stock VoxCPM2; only the backbone that turns text (and audio-latent context) into hidden states is swapped.

**Status:** the `voxcpm2-qwen` architecture, checkpoint-init tooling, and training/inference scripts are built and structurally verified (see [POC_QWEN_BACKBONE.md](POC_QWEN_BACKBONE.md) for exactly what's been tested vs. not). No training run has been completed yet — this is the scaffold to train it on your own data, not a released model.

## 🚀 Quick Start (stock VoxCPM2)

This section is unmodified from upstream — it covers the original VoxCPM2 architecture and pretrained weights, still fully present and usable in this fork.

### Installation

```sh
pip install -e .
```

> **Requirements:** Python ≥ 3.10 (<3.13), PyTorch ≥ 2.5.0, CUDA ≥ 12.0. See the [upstream Quick Start Docs](https://voxcpm.readthedocs.io/en/latest/quickstart.html) for details.

### Python API

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained(
  "openbmb/VoxCPM2",
  load_denoiser=False,
)

wav = model.generate(
    text="VoxCPM2 is the current recommended release for realistic multilingual speech synthesis.",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("demo.wav", wav, model.tts_model.sample_rate)
```

**Voice Design** (no reference audio — put the description in parentheses at the start of `text`):

```python
wav = model.generate(
    text="(A young woman, gentle and sweet voice)Hello, welcome to VoxCPM2!",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
```

**Controllable Voice Cloning** (reference audio, with optional style control):

```python
wav = model.generate(
    text="This is a cloned voice generated by VoxCPM2.",
    reference_wav_path="path/to/voice.wav",
)
```

**Ultimate Cloning** (reference audio + its transcript, for maximum similarity):

```python
wav = model.generate(
    text="This is an ultimate cloning demonstration using VoxCPM2.",
    prompt_wav_path="path/to/voice.wav",
    prompt_text="The transcript of the reference audio.",
    reference_wav_path="path/to/voice.wav",
)
```

**Streaming:**

```python
import numpy as np

chunks = []
for chunk in model.generate_streaming(text="Streaming text to speech is easy with VoxCPM!"):
    chunks.append(chunk)
wav = np.concatenate(chunks)
```

### CLI Usage

```bash
# Voice design (no reference audio needed)
voxcpm design --text "VoxCPM2 brings studio-quality multilingual speech synthesis." --output out.wav

# Voice cloning (reference audio)
voxcpm clone --text "This is a voice cloning demo." --reference-audio path/to/voice.wav --output out.wav

# Batch processing
voxcpm batch --input examples/input.txt --output-dir outs

# Help
voxcpm --help
```

### Web Demo

```bash
python app.py --port 8808  # then open http://localhost:8808
python app.py --device auto  # auto | cpu | mps | cuda | cuda:N
```

> Full parameter reference, multi-scenario examples, production serving options (Nano-vLLM, vLLM-Omni, llama.cpp-omni/GGUF) and voice cloning tips for the **stock** model are in the [upstream docs](https://voxcpm.readthedocs.io/en/latest/) — those external inference engines target the officially released `openbmb/VoxCPM2` weights and are not applicable to the `voxcpm2-qwen` checkpoints this fork produces.

## 🧩 Qwen-Backbone PoC (Hindi + English)

New in this fork. Full write-up, verification status, and design rationale: **[POC_QWEN_BACKBONE.md](POC_QWEN_BACKBONE.md)**.

What's new on disk:

| Path | What it is |
| --- | --- |
| `src/voxcpm/modules/qwen_backbone/` | `QwenLMBackbone` — wraps a pretrained Qwen2-family causal LM (default `Qwen/Qwen2.5-0.5B`) behind the same interface VoxCPM2's MiniCPM-4 backbone exposes. |
| `src/voxcpm/model/voxcpm2_qwen.py` | `VoxCPMQwenModel` — wires the Qwen backbone into the VoxCPM2 pipeline; handles the audio-marker-token/vocabulary fix Qwen's tokenizer requires; builds fresh checkpoint directories. |
| `scripts/init_voxcpm_qwen_poc.py` | Builds an initial checkpoint (Qwen backbone from HuggingFace + freshly initialized acoustic modules + AudioVAE reused from a stock VoxCPM2 snapshot). |
| `scripts/test_voxcpm_qwen_infer.py` | Inference/testing against a trained `voxcpm2-qwen` checkpoint. |
| `conf/voxcpm_v2_qwen/voxcpm_poc_hi_en.yaml` | Full-fine-tune training config for the Hindi+English PoC (see the file's header comment for why this must be full fine-tune, not LoRA). |

Minimal path to a trained checkpoint:

```bash
# 1. Get AudioVAE weights to reuse (frozen) from a stock VoxCPM2 snapshot
python -c "from voxcpm import VoxCPM; VoxCPM.from_pretrained('openbmb/VoxCPM2', load_denoiser=False)"

# 2. Build the initial voxcpm2-qwen checkpoint
python scripts/init_voxcpm_qwen_poc.py \
    --save-path ./pretrained_models/VoxCPM2-Qwen2.5-0.5B-poc \
    --qwen-model Qwen/Qwen2.5-0.5B \
    --reference-voxcpm2-path <path to the snapshot from step 1>

# 3. Point conf/voxcpm_v2_qwen/voxcpm_poc_hi_en.yaml at your data + the checkpoint above, then train
python scripts/train_voxcpm_finetune.py --config_path conf/voxcpm_v2_qwen/voxcpm_poc_hi_en.yaml

# 4. Test a trained checkpoint
python scripts/test_voxcpm_qwen_infer.py \
    --ckpt_dir ./checkpoints/voxcpm2_qwen_poc_hi_en/step_0002000 \
    --text "यह एक परीक्षण वाक्य है।" \
    --output test_hi.wav
```

Training manifest format is unchanged from stock VoxCPM2 — JSONL, one `{"audio": "...", "text": "...", "duration": ..., "dataset_id": ...}` per line (see `examples/train_data_example.jsonl`). Multi-speaker data is expected and fine: voice identity comes from reference-audio conditioning at inference time, not a fixed per-speaker embedding table.

## ⚙️ Fine-tuning

VoxCPM supports full fine-tuning (SFT) and LoRA fine-tuning on the stock architecture, plus full fine-tuning on the `voxcpm2-qwen` PoC architecture added by this fork.

```bash
# Stock VoxCPM2 — LoRA fine-tuning (parameter-efficient, recommended for adapting an already-trained checkpoint)
python scripts/train_voxcpm_finetune.py --config_path conf/voxcpm_v2/voxcpm_finetune_lora.yaml

# Stock VoxCPM2 — full fine-tuning
python scripts/train_voxcpm_finetune.py --config_path conf/voxcpm_v2/voxcpm_finetune_all.yaml

# This fork — Qwen-backbone PoC (full fine-tune only; see conf file header for why)
python scripts/train_voxcpm_finetune.py --config_path conf/voxcpm_v2_qwen/voxcpm_poc_hi_en.yaml

# WebUI for stock LoRA training & inference
python lora_ft_webui.py   # then open http://localhost:7860
```

> LoRA is only appropriate when adapting an already-trained checkpoint (stock VoxCPM2). The `voxcpm2-qwen` PoC's acoustic modules (LocEnc, most of the residual LM, most of LocDiT) start randomly initialized and need full fine-tuning to train at all — see the warning at the top of `conf/voxcpm_v2_qwen/voxcpm_poc_hi_en.yaml`.

## ⚠️ Risks and Limitations

- **Potential for Misuse:** voice cloning can generate highly realistic synthetic speech. It is **strictly forbidden** to use this for impersonation, fraud, or disinformation. Clearly mark any AI-generated content.
- **Controllable Generation Stability:** Voice Design and Controllable Voice Cloning results can vary between runs — try generating 1–3 times to get the desired voice or style.
- **Qwen-backbone PoC specifically:** unlike stock VoxCPM2, this variant has not been trained to convergence by anyone yet. Expect to need real iteration (data, steps, possibly hyperparameters) before it produces intelligible speech at all — see [POC_QWEN_BACKBONE.md](POC_QWEN_BACKBONE.md)'s verification status.
- **Usage:** released under the Apache-2.0 license. For production use, conduct thorough testing and safety evaluation for your use case.
